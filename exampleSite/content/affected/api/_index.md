title: API
---

The API powers account access, product data, and customer-facing integrations.

During active incidents, updates here focus on request success, response latency, and any degraded endpoints. Experiments and rollout notes may appear here when they affect API traffic without changing the overall service state.

Most API changes are released gradually. If a rollout needs closer attention, it will be linked below as an operational record rather than marked as downtime.
